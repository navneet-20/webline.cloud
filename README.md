# Webline Cloud — Premium GitHub Pages Site

Static, dependency-light website for Webline Cloud.

## Files
- `index.html` — page structure/content
- `style.css` — premium responsive design
- `script.js` — `/` search shortcut and website search

## Deploy on GitHub Pages
1. Create/open the repository used for `webline.cloud`.
2. Replace the existing site files with these three files.
3. Commit and push to the branch configured for GitHub Pages.
4. Keep the custom domain/CNAME configuration already used by your current site.
